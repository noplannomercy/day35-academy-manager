## 📋 페이지별 테스트 체크리스트

### ✅ 대시보드 (/)

```
□ 페이지 접근 가능
□ 6개 통계 카드 표시
  - 전체 수강생
  - 전체 반
  - 이번 달 수익
  - 미납 건수
  - 미납 금액
  - 연체 건수
□ 미납자 목록 표시
□ 오늘 시간표 표시
□ 오늘 리마인더 표시
□ 최근 상담 기록 표시
□ 수강 등록 추이 차트 표시
□ Console 에러 없음
```

---

### ✅ 수강생 관리 (/students)

#### 목록 페이지
```
□ 페이지 접근 가능
□ 수강생 목록 표시
□ 검색창 입력 가능
□ 상태 필터 작동 (전체/활동중/일시중단/탈퇴)
□ 페이지네이션 작동
□ Excel 내보내기 버튼 클릭
□ "등록" 버튼 클릭 → /students/new 이동
```

#### 등록 페이지 (/students/new)
```
□ 폼 표시
□ 이름 입력
□ 전화번호 입력
□ 레벨 선택
□ 유입경로 선택
□ "등록" 버튼 클릭
□ 성공 시 Toast 알림
□ 목록 페이지로 이동
```

#### 상세 페이지 (/students/[id])
```
□ 학생 정보 표시
□ 탭 전환 가능
  - 수강 중인 반
  - 출석 기록
  - 수납 내역
  - 상담 기록
□ "수정" 버튼 → 수정 페이지 이동
□ "삭제" 버튼 (활성 수강이 있으면 차단)
```

---

### ✅ 강사 관리 (/instructors)

#### 목록 페이지
```
□ 페이지 접근 가능
□ 강사 목록 표시
□ 검색창 작동
□ "등록" 버튼 클릭 → /instructors/new
```

#### 등록 페이지 (/instructors/new)
```
□ 폼 표시
□ 이름, 전화번호 입력
□ 과목 선택 (복수 선택 가능)
□ 월급 입력
□ "등록" 버튼 클릭
□ Toast 알림
```

#### 수정 페이지 (/instructors/[id]/edit)
```
□ 기존 정보 표시
□ 정보 수정
□ "저장" 버튼 클릭
```

---

### ✅ 반 관리 (/classes) ⚠️ **중요**

#### 목록 페이지
```
□ 페이지 접근 가능
□ 반 목록 표시
□ 필터 작동 (전체/모집중/마감)
□ "등록" 버튼 → /classes/new
```

#### 등록 페이지 (/classes/new) ⚠️ **Critical**
```
□ 폼 표시
□ 반 이름 입력
□ 과목 Select 열기
  → 과목 옵션 표시되는지 확인
  → 옵션 선택 가능한지 확인
□ 강사 Select 열기
  → 강사 옵션 표시되는지 확인
  → 옵션 선택 가능한지 확인
□ 교실 Select 열기
  → 교실 옵션 표시되는지 확인
  → 옵션 선택 가능한지 확인
□ 정원 입력
□ 수강료 입력
□ 시간표 추가
  - 요일 선택
  - 시작/종료 시간 입력
□ "등록" 버튼 클릭
□ Toast 알림
□ Console 에러 없음
```

#### 상세 페이지 (/classes/[id])
```
□ 반 정보 표시
□ 탭 전환
  - 수강생 탭
  - 대기자 탭
□ 수강생 목록 표시
□ "수강 등록" 버튼 클릭
  → 학생 검색 Dialog 열림
  → 학생 선택 및 등록
□ 대기자 목록 표시
□ "수정" 버튼 → /classes/[id]/edit
```

#### 수정 페이지 (/classes/[id]/edit) ⚠️ **Critical**
```
□ 폼 표시
□ **과목 Select에 기존 값이 선택된 상태로 표시**
□ **강사 Select에 기존 값이 선택된 상태로 표시**
□ **교실 Select에 기존 값이 선택된 상태로 표시**
□ 값 변경 가능
□ "저장" 버튼 클릭
□ Toast 알림
□ Console 에러 없음
```

### ✅ 출석 관리 (/attendance)

```
□ 페이지 접근 가능
□ 탭 전환 (출석 체크 / 출석 통계 / 보강 관리)
□ 출석 체크 탭:
  - 반 선택 Select
  - 날짜 선택 DatePicker
  - 수강생 목록 표시
  - 출석 상태 변경 (출석/결석/지각/인정결석)
  - 전체 출석 처리 체크박스
  - 메모 입력
  - "일괄 저장" 버튼 클릭
  - Toast 알림
□ 보강 관리 탭:
  - 결석자 보강 예약 버튼
  - 보강 날짜/시간 입력
  - 보강 상태 변경 (완료/취소)
□ Excel 내보내기 버튼
```

---

### ✅ 수납 관리 (/payments)

#### 목록 페이지
```
□ 페이지 접근 가능
□ 수납 목록 표시
□ 월별 필터
□ 상태별 필터 (전체/미납/부분납부/완납/연체)
□ 검색 기능
□ 수납 요약 카드 (총액/납부액/미납액)
□ "등록" 버튼 → 수납 등록 Dialog
□ Excel 내보내기 버튼
```

#### 수납 등록
```
□ Dialog 열림
□ 학생 선택
□ 반 선택
□ 월 선택
□ 금액 자동 입력 or 수동 입력
□ 일할 계산 체크박스
□ "등록" 버튼
□ Toast 알림
```

#### 상세 페이지 (/payments/[id])
```
□ 수납 정보 표시
□ 학생/반 정보 표시
□ 납부 현황 표시
□ "납부 처리" 버튼
  - 전액 납부 / 반액 납부 선택
  - 납부 방법 선택 (현금/카드/이체)
  - 납부일 선택
  - 확인 → Toast 알림
□ "환불 처리" 버튼
  - 환불 금액 입력
  - 환불 사유 입력
  - 환불 방법 선택
  - 확인 → Toast 알림
□ 환불 내역 표시
```

### ✅ 시간표 (/schedule)

```
□ 페이지 접근 가능
□ 주간/월간 토글 버튼
□ 주간 뷰:
  - 주간 시간표 표시
  - 수업 정보 (반명, 시간, 강사)
  - 휴일 표시
□ 월간 뷰:
  - 월간 달력 표시
  - 수업 개수 표시
  - 휴일 표시
□ 강사 필터
□ 교실 필터
□ 날짜 이동 (이전/다음)
```

### ✅ 휴일 관리 (/holidays)

```
□ 페이지 접근 가능
□ 휴일 목록 표시
□ "공휴일 자동 등록" 버튼
  - 연도 선택
  - 확인 → Toast 알림
  - 목록에 공휴일 추가 확인
□ "휴일 등록" 버튼
  - 날짜 선택
  - 휴일명 입력
  - 유형 선택 (공휴일/자체휴일)
  - 확인 → Toast 알림
□ 삭제 버튼
```

---

### ✅ 설정 (/settings)

```
□ 페이지 접근 가능
□ 탭 전환 (학원 정보 / 마스터 데이터 / 백업)
□ 학원 정보 탭:
  - 학원명, 전화번호, 주소 표시
  - 운영시간 표시
  - "수정" 버튼
  - 정보 변경 후 저장
  - Toast 알림
□ 마스터 데이터 탭:
  - 레벨 목록 표시
  - 과목 목록 표시
  - 교실 목록 표시
  - 유입경로 목록 표시
  - 각 항목 추가/수정/삭제
□ 백업 탭:
  - "백업 다운로드" 버튼
    → db.json 파일 다운로드
  - "복원" 버튼
    → 파일 선택 후 복원
```
