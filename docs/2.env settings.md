## 환경설정 (루트 설치)

```bash
# 1. Next.js 프로젝트 생성 (현재 폴더에 바로)
npx create-next-app@latest . --typescript --tailwind --eslint --app --src-dir --import-alias "@/*"
```

```bash
# 2. shadcn/ui 초기화
npx shadcn@latest init
```

```bash
# 3. shadcn 컴포넌트 설치 (Day 35 확장)
npx shadcn@latest add button input card dialog table select dropdown-menu badge tabs textarea label separator alert-dialog checkbox popover calendar command form sheet scroll-area tooltip switch sonner
```

```bash
# 4. 폼 검증 (React Hook Form + Zod)
npm install react-hook-form @hookform/resolvers zod
```

```bash
# 5. 날짜 처리
npm install date-fns
```

```bash
# 6. 차트 패키지
npm install recharts
```

```bash
# 7. Excel 내보내기
npm install xlsx
```

```bash
# 8. UUID 생성
npm install uuid
npm install -D @types/uuid
```

```bash
# 9. data 폴더 생성 (JSON 저장소)
mkdir data
```

```bash
# 10. 빌드 확인
npm run build
```
