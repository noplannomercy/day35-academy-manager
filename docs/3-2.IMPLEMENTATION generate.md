Create specs/IMPLEMENTATION.md:

Phase-by-phase implementation plan with checkboxes.

Each Phase include:
1. Goal
2. Estimated time
3. Files to create (checklist format)
4. Implementation strategy
5. Testing checkpoint (checklist)
6. Acceptance criteria (checklist)

Phase structure (Backend First 전략):

### Phase A: Backend (API 먼저)
- Phase 1: Storage & Types (lib/storage.ts, types, constants, data/db.json)
- Phase 2: Quote API Routes (7개: CRUD + status + duplicate)
- Phase 3: Client API Routes (4개: CRUD)
- Phase 4: Stats, Settings, Backup API Routes (5개)
- Phase 5: Backend curl 테스트 전체 확인

### Phase B: Frontend (확정된 API 호출)
- Phase 6: Layout & Navigation (AppLayout, Sidebar, routing)
- Phase 7: Common Components (ConfirmDialog, Toast, Pagination, etc.)
- Phase 8: Settings & Client Pages (간단한 CRUD 페이지 먼저)
- Phase 9: Quote Pages (QuoteList, QuoteForm, QuoteDetail)
- Phase 10: Dashboard (StatCards, Charts, RecentQuotes)
- Phase 11: PDF & Backup/Restore & Polish

CRITICAL CONSTRAINTS:
- Backend First: Phase A 완료 후 Phase B 시작
- 저장소: data/db.json (lib/storage.ts로 접근)
- Phase 5에서 curl로 전체 API 테스트 필수
- 각 Phase 완료 후 npm run build 실행

⭐ Phase 5 curl 테스트 포맷:
```bash
# 예시: 견적서 생성
curl -X POST http://localhost:3000/api/quotes \
  -H "Content-Type: application/json" \
  -d '{"clientId":"sample-client-1","items":[...]}'

# 예상 응답:
# {"success":true,"data":{"id":"...","quoteNumber":"QT-20260201-001",...}}
```
→ 각 API별 curl 명령어 + 예상 응답 JSON 포함
