## 저장소 변경: LocalStorage → JSON 파일 (fs)

### 변경 이유
Next.js API Routes는 서버 사이드에서 실행되므로 LocalStorage 접근 불가.
Backend First 전략에서 curl 테스트를 위해 서버 사이드 저장소 필수.

### 수정 사항

#### 1. docs/SRS_FINAL.md
- 섹션 1 개요: 저장소 "LocalStorage" → "JSON 파일 (data/db.json)"
- 섹션 4 NFR-003: "LocalStorage에 JSON으로 저장" → "서버 JSON 파일로 저장"
- 섹션 4 NFR-003: "데이터 용량 제한 고려 (5MB)" → 제거 또는 "파일 시스템 기반"으로 변경
- 섹션 7 제약사항: "데이터베이스 없음 (LocalStorage)" → "데이터베이스 없음 (JSON 파일)"
- 섹션 8 기술 스택: 저장소 "LocalStorage" → "JSON File (fs)"

#### 2. specs/ARCHITECTURE.md
- 섹션 2 시스템 아키텍처: Storage를 LocalStorage → JSON File로 변경
- 섹션 4 LocalStorage 구조 → "데이터 저장소 구조"로 섹션명 변경
  - Storage Keys 테이블 유지하되 "JSON 파일 내 구조"로 설명 변경
  - 파일 경로: data/db.json
  - 구조:
```json
    {
      "quotes": [],
      "clients": [],
      "settings": null,
      "quoteCounter": 0
    }
```
- 섹션 4 Mermaid 다이어그램: LocalStorage → JSON File로 변경
- 섹션 5 데이터 흐름: "LocalStorage에서 조회" → "JSON 파일에서 조회"

- 프론트엔드 컴포넌트: 변경 없음
