
## Day 34 수정 버전

### Phase A용 (Phase 1-5: 백엔드)

```markdown
specs/IMPLEMENTATION.md, CLAUDE.md 읽기

## Phase {N} 실행 (Backend)

### 실행 방식
coder-expert 서브에이전트 배포하여 구현

### 구현 규칙
1. Phase {N} 섹션 전체를 먼저 읽고 시작
2. "Files to Create" 목록 순서대로 구현
3. "Implementation Strategy" 단계별로 따르기
4. Context7 MCP로 최신 문서 참조 (Next.js App Router API Routes)

### 빌드 검증
파일 3개마다:
```bash
npm run build
```
- 에러 0개여야 다음 진행
- 에러 발생 시: 즉시 수정 → 재빌드 → 계속
- 동일 에러 3회 실패 시: 보고 후 중단

### API 검증 (Phase 2-4 완료 후)
```bash
# API Route 파일 목록 확인
find src/app/api -name "route.ts" | wc -l
# 예상: Phase 2 완료 시 4개, Phase 3 완료 시 6개, Phase 4 완료 시 9개
```

### curl 테스트 (Phase 5)
IMPLEMENTATION.md Phase 5의 curl 명령어를 순서대로 실행
- npm run dev 실행 상태에서 테스트
- 각 응답이 예상 형식과 일치하는지 확인
- 에러 케이스도 반드시 테스트

### 완료 보고서 저장
docs/reports/phase{N}-report.md 파일 생성:
```markdown
# Phase {N} 완료 보고서

## 생성된 파일
- [x] file1.ts
- [x] file2.ts

## 빌드 결과
- npm run build: 성공/실패
- 에러: (있으면 기록)

## API Route 검증
- route.ts 파일 수: N개 (예상: N개)

## Testing Checklist 결과
- [x] 테스트1: 통과
- [ ] 테스트2: 실패 - 원인: xxx

## Acceptance Criteria 충족
- [x] 기준1: 충족

## 발견된 이슈
- (없으면 "없음")

## Phase {N+1} 진행 가능
예/아니오
```

### 마무리
1. docs/reports/phase{N}-report.md 저장
2. IMPLEMENTATION.md 체크박스 → [x] 업데이트
3. Phase {N} 완료 후 중단
```

### Phase B용 (Phase 6-11: 프론트엔드)

```markdown
specs/IMPLEMENTATION.md, CLAUDE.md, specs/COMPONENTS.md 읽기

## Phase {N} 실행 (Frontend)

### 실행 방식
coder-expert 서브에이전트 배포하여 구현

### 구현 규칙
1. Phase {N} 섹션 전체를 먼저 읽고 시작
2. "Files to Create" 목록 순서대로 구현
3. "Implementation Strategy" 단계별로 따르기
4. Context7 MCP로 최신 문서 참조 (Next.js, shadcn, Recharts 등)
5. API 호출은 lib/api.ts 통해서만

### 빌드 검증
파일 3개마다:
```bash
npm run build
```
- 에러 0개여야 다음 진행
- 에러 발생 시: 즉시 수정 → 재빌드 → 계속
- 동일 에러 3회 실패 시: 보고 후 중단

### 프론트엔드 검증 (Phase 완료 후)
```bash
# 컴포넌트에서 직접 fetch 호출 확인
grep -r "fetch(" src/components/ src/app/ --include="*.tsx" | grep -v "lib/api" && echo "❌ lib/api.ts 외 fetch!" || echo "✅ API 호출 집중됨"
```

### 자체 테스트
모든 파일 생성 후:
1. `npm run dev` 실행
2. IMPLEMENTATION.md Phase {N}의 "Testing Checklist" 항목 하나씩 검증
3. "Acceptance Criteria" 모두 충족 확인
