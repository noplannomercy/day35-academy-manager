## 요구사항 요약 (SRS 대비 추가/변경 사항)

### 추가 기능
1. **부분 납부** - 전액/반액 선택 납부 지원
2. **환불 처리** - 납부 건에 대한 환불 기능
3. **일할 계산** - 월 중간 등록 시 자동 일할 계산
4. **보강 예약** - 결석 시 같은 반 다른 시간대 보강 예약
5. **휴일 관리** - 공휴일 자동 + 수동 휴원일 등록
6. **월간 시간표** - 주간 + 월간 시간표 표시
7. **대기자 관리** - 정원 초과 시 대기 등록 (FIFO 방식)
8. **등급 시스템** - 설정에서 등급 정의, 수강생 할당
9. **등록 경로** - 설정에서 경로 목록 관리
10. **시간표 충돌 검사** - 수강생 다중 수강 시 충돌 경고
11. **강사 다중 과목** - 강사 subject를 배열로 변경
12. **강사 급여 관리** - 고정 급여 등록/지급 관리
13. **과목 관리** - 설정에서 과목 목록 관리
14. **교실 관리** - 설정에서 교실 목록 관리
15. **상담 리마인더** - nextAction 날짜 + 대시보드 알림
16. **대시보드 미납자 목록** - 미납 수강생 이름+금액 표시
17. **통합 검색** - 헤더에 전체 통합 검색창
18. **Excel 내보내기** - 주요 데이터 전체 Excel 저장

### 변경 사항
1. **페이지네이션** - 20건 → 10건으로 변경
2. **설정 통합** - 기본 정보 + 운영 + 공휴일 + 등급 + 과목 + 교실 + 등록경로 + 백업 통합
3. **휴원일 출석** - 휴원일은 출석 체크 비활성화
4. **inactive 수납** - inactive 수강생 수납 생성 불가
5. **정원 초과** - 경고 없이 완전 차단 (대기자 전환)

### 제외된 기능
- 할인 정책 (형제자매/다중수업 할인)
- 수강생 사진
- 수납 자동 생성
