## 2. 종목 감지 방식 명시 (ARCHITECTURE.md)

### 종목 감지 흐름 추가
- 위치: 데이터 흐름 섹션에 추가
- 방식: 프론트엔드에서 사용자 메시지 파싱 (STOCK_MAP 사용)
```
사용자 입력 → detectStock(message) → 종목 코드 반환
  → 종목 있으면: 병렬 API 호출
  → 종목 없으면: 채팅만 표시
```
